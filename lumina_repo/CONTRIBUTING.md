# Contributing

## Setup

Clone the project

```bash
git clone https://github.com/Tanushree-RD/lumina.git
```

Install packages

```bash
npm install
```

Run locally

```bash
npm run dev
```

---

## Branch Naming

Use

```
feature/...
fix/...
refactor/...
docs/...
```

Examples

```
feature/csv-upload

feature/model-api

feature/dashboard

fix/navbar

refactor/ui
```

---

## Commit Convention

```
feat:
fix:
docs:
refactor:
style:
```

Example

```
feat: add upload component

fix: candidate ranking layout

docs: update README
```

---

## Before Opening PR

- Code builds successfully
- No console errors
- No TypeScript errors
- Responsive layout
- Follow existing design

---

Avoid pushing directly to main.
